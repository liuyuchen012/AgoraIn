# AgoraIn v4 使用手册（初稿）

> 面向学校管理员与任课教师，指导完成安装、首次配置与日常教学操作。
> 部署相关见 `deployment.md`，架构与 API 契约见 `architecture.md` / `api-contract.md`。

## 1. 系统组成

| 组件 | 说明 | 运行环境 |
| --- | --- | --- |
| 桌面端（AgoraIn） | 大屏打卡 / 控制模式 / 教师模式，本地优先可离线运行 | Windows 10+（Linux/macOS 可编译） |
| 服务器（AgoraIn.Server） | REST API + SignalR + Web 管理面板静态托管 | Linux（生产）/ Windows |
| Web 管理面板 | 浏览器访问服务器域名，教师/管理员日常后台 | Chrome / Edge |
| 移动端（AgoraIn.Mobile） | 学生扫码签到、历史记录、答题卡拍照上传 | Android（iOS/Windows 可编译） |
| 家长端小程序 | 通知、资源、成绩、值日、留言 | 微信（AppID：wxa2003db2b4693a66） |
| ClassIsland 插件 | 教室一体机接收呼叫与语音播报（广播由插件承担） | ClassIsland .NET 8 |

## 2. 安装

### 2.1 桌面端（Windows）

1. 从安装包（zip 自包含，解压即用）解压到本地目录；
2. 双击 `AgoraIn.exe` 启动（已禁用 CET 检查，兼容 Windows 10）；
3. 首次启动在「设置」中配置：班级名称、按钮行列数、每小时课时消耗、服务器地址（默认锁定官方服务器）。

### 2.2 服务器（Linux）

1. 解压 `AgoraIn-Server-linux-x64.tar.gz`，执行 `./AgoraIn.Server`（默认端口 5250，可用 `--urls` 指定）；
2. 数据目录默认为程序目录下 `data/`（SQLite）；可用环境变量 `Data__Directory` 重定向，确保运行用户有写权限；
3. 浏览器打开 `http://<host>:5250`，按 Web 面板引导完成管理员初始化（首次访问出现创建管理员页）。

### 2.3 移动端（Android）

安装 `AgoraIn-Android.apk`，登录教师分发的账号即可。扫码签到需要相机权限。

## 3. 首次配置（管理员）

1. **初始化向导**：首次访问 Web 面板创建管理员账号（`/setup`，仅无用户时开放）；
2. **班级与学生**：「班级管理」建班级 →「学生管理」录入学生（学号用于考号匹配与点名顺序）；
3. **用户与权限**：「用户管理」创建教师/子账户；角色权限矩阵见 `architecture.md`；
4. **授权激活**：「授权管理」输入离线激活码（授权码由 LicenseTool 签发，绑定机器指纹与设备数）；
5. **AI 批改**（可选）：`appsettings.json` 配置 `DeepSeek:ApiKey`，或登录后在「AI 批改设置」在线调整模型/温度/低置信度阈值与图像外发隐私开关。

## 4. 桌面端三模式

顶部标题栏点击模式文字循环切换 **大屏模式 → 控制模式 → 教师模式**。

- **大屏模式**：任务树/标签页 + 学生按钮网格打卡；右键学生按钮取消打卡；前三名金/银/铜高亮；打卡数据支持 CSV 导入导出。
- **控制模式 / 教师模式**：内嵌官方 Web 管理面板（课时划消、排课、点名、积分、值日、试卷批改等），断网时桌面本地功能不受影响。

## 5. 扫码签到（教师）

1. Web 面板或桌面端创建/选择一个**签到任务**；
2. 调用「生成签到码」（`POST /api/v4/checkin/signin-codes`）：可设置教室、科目、签到密码、有效期；
3. 大屏展示二维码（内容形如 `https://<server>/signin?code=ABC123`）；
4. 学生在移动端「扫码签到」输码/扫码提交（重名班级须填学号）；
5. 签到即时通过 SignalR 推送到同班级大屏；`下码` 后签到码失效。

## 6. 点名 / 积分 / 值日 / 座位（班级中心）

- **点名**：创建点名场次（随机加权 / 顺序 / 指定）→ 逐次 `pick` 落点 → 标记答到/缺勤/迟到，可携带积分联动（如答到 +1）；结束场次后可查看报表（出勤率、逐生被点次数）。随机模式默认启用「近期未点过优先」加权。
- **座位**：按班级创建座位布局（行列、讲台方位、禁用空位、分组），支持拖拽调座、一键随机换座（换座前自动留存快照，可随时回看历史布局）。
- **积分**：规则管理（每日上限、适用班级）→ 流水（来源：手工/打卡/点名/值日/答题卡/修正）→ 积分榜；教师修正须填写原因并留痕。
- **值日**：岗位管理（名称/图标/人数）→ 按周/按日轮换生成值日表 → 记录完成情况（未完成可联动扣分）。

## 7. 电子答题卡与 AI 阅卷

完整流程：**出卷 → 生成答题卡 → 打印 → 作答 → 拍照上传 → 识别 → 批改 → 成绩统计**。

1. **出卷**（Web「试卷管理」）：录入题目（单选/多选/判断/填空/简答/作文），设置分值、标准答案、评分要点（简答/作文必填，AI 批改依据）、知识点标签；可将试卷标记为「题库模板」供其他试卷复用。
2. **生成答题卡**：A4 版面自动排版（四角定位标记、考号涂卡/条码区、客观题涂卡区、主观题边界框、页脚二维码）；支持**按班级批量生成一人一张带条码**的页面。
3. **上传**：扫卡记录对话框上传答题卡照片（手机拍摄/批量上传）。
4. **识别与自动判分**：服务端调用视觉模型识别考号与客观题 → 客观题与标准答案比对自动判分；考号自动匹配学号（需教师确认绑定）。
5. **批改状态机**：`未批 → AI已批 →（低置信度→）待人工 → 已确认`。主观题点「AI批改」整卷批改；「逐题」对话框可查看识别内容、AI 建议分并**人工复判改分**（留痕）；只有「已确认」计入成绩。
6. **成绩统计**：「成绩统计」页按学生总分/按题得分率分析，支持导出 CSV（Excel 直接打开）。

> AI 安全与合规：学生作答图像仅用于批改；「AI 批改设置」中的图像外发开关关闭后，识别停用，主观题仅支持手判。批改模型请配置支持图像输入的多模态模型（如 GLM-4V / Qwen-VL）。

## 8. 家长端小程序

1. 教师「学生管理」生成 6 位绑定邀请码 → 家长登录后输入邀请码绑定孩子（支持多孩切换）；
2. 家长可查看：通知与已读回执、班级资源（下载/预览）、打卡考勤概览、积分、值日表现、成绩概览（受隐私开关 `parent.showScores` 控制，默认关闭）、与教师留言；
3. 通知支持定时发布（`publishAt` 未来时刻到点可见）。

## 9. 常见问题

- **桌面端无法启动（Win10）**：确认使用 v4 安装包（已内置 CET 兼容处理，`CETCompat=false`）。
- **SQLite "unable to open database file"**：数据目录不存在或无写权限，检查 `Data__Directory` 与目录权限。
- **答题卡识别失败**：检查 `DeepSeek:ApiKey`、识别模型是否为多模态模型、图像外发开关是否被关闭；调用日志见「AI 批改设置」页。
- **扫码签到 404/过期**：签到码已被下码或过期，请重新生成。
- **宝塔环境安全规则拦截 SPA 路由**（如 `/license`）：参照 `deployment.md` 的正则放行方案处理。
